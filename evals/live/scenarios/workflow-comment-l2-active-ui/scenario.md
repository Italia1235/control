## Evidence contract

Use schemaVersion=1, scenario=L2, workflow, project, actionId, noScreenActionId, screenIds, setupTrace/setupConversation and a `steps` entry comment-add (the single configure_workflow plan: screen SET + comment_required) with beforeXml/afterXml refs, previewSeq and operationId. Every reference is `{path,sha256}` pointing to captured bytes. ui[] has seven kinds: dialog, empty, old-comment, nonempty, whitespace, no-screen, sr-open-save. Each includes workflow, actionId (no-screen uses noScreenActionId), page ref to raw UI HTML, issueKey/current comment and beforeIssue/afterIssue refs to actual Jira read-only issue JSON (fields.status.id and complete fields.comment.comments). HTML must identify the issue; old-comment readback must contain a real old comment. no-screen also supplies beforeXml. sr-open-save instead supplies openPage (editor), page (saved list), beforeXml/afterXml and get_workflow_validators readback refs. Before/after XML refers to the added Control validator, not a different UUID fixture. Hashes prove artifact integrity, not UI authenticity. Capture provenance remains operator responsibility.

Save via existing runner. Read-only/no-model verification is `node evals/live/run.mjs --regrade <saved-run-folder>` with setup.json, tool-trace.json, conversation.md, lifecycle.json, evidence.json and artifacts. Missing XML/UI is failure; evidence of earlier runs is not current evidence.
