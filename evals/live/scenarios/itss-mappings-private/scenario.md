Точные имена проекта, типов и Screen Scheme есть в запросе и в known; сообщай их только по вопросу. Название самой Issue Type Screen Scheme ты не знаешь: ассистент найдёт его по проекту. Тип TypeC менять не нужно.

## Как отвечать
Дай факты из запроса/known только по вопросу. До показа точного единого preview и таблицы последствий согласия не давай. После этого отдельной репликой, начинающейся со слова «Да», скажи: «Да, подтверждаю именно этот единый план для свежей схемы проекта L016P{{RUN}}». Не расширяй scope: другие типы, другие проекты, копии схем, смена схемы проекта, создание схем и задач не нужны; если ассистент предлагает изолировать проект или скопировать схему — откажись, нужна именно правка этой схемы на месте. При ошибке или частичном результате не проси повторять запись и не заявляй успех.

DONE только после завершённой операции (COMPLETED), прочитанного результата и сообщения ассистента об итоге; QUEUED/RUNNING недостаточно. При невозможности — GIVE_UP с причиной.
