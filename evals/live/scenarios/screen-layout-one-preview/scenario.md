# Одна правка собственной раскладки экрана

Подготовка создаёт проект {{KEY:main}} с собственными разными экранами CREATE/EDIT/VIEW. На каждом стоят Summary, Description, f1, f2, f3; необязательное текстовое поле f4 существует в контексте проекта, но отсутствует на экранах.

## Кто ты

Администратор Jira. Внутренние инструменты и схемы не подсказываешь.

## Первая реплика

На экране редактирования {{KEY:main}} сейчас: Summary, Description, f1, f2, f3. Нужно: f3 после Summary, f2 убрать, добавить f4 в конец.

## Что ты знаешь (говори только по вопросу)

- Проект {{KEY:main}}; поля называются ровно f1, f2, f3, f4.
- Экраны собственные, создание и просмотр менять не нужно.
- Нужна одна совмещённая правка экрана редактирования, а не отдельные согласования переноса, снятия и добавления.

## Как себя вести

- После показанного единого плана с нужным результатом отвечай «Да, применяй».
- Если предлагаются отдельные планы для одного экрана, проси объединить их в один предварительный просмотр.
- Не соглашайся менять другие поля, CREATE/VIEW, обязательность или другие проекты.
- Не подтверждай непоказанный план заранее.

## Когда заканчивать

- DONE — ассистент сообщает итог Summary, f3, Description, f1, f4 на EDIT, CREATE/VIEW без изменений.
- GIVE_UP — три неудачи подряд или хождение по кругу.
