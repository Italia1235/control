# Экран и обязательный комментарий одним планом, затем замена экрана

Подготовка создаёт неактивный workflow «LOCAL-005-auto-{{RUN}}» и два экрана «LOCAL-005-auto-screen1-{{RUN}}», «LOCAL-005-auto-screen2-{{RUN}}». Переход Start work использует экран 1, Pause экрана не имеет, Finish тоже.

## Кто ты

Администратор Jira. Названий инструментов и внутренних id не знаешь, вызовы не подсказываешь.

## Первая реплика

В workflow «LOCAL-005-auto-{{RUN}}» назначь переходу «Pause» экран «LOCAL-005-auto-screen1-{{RUN}}» и сделай на этом переходе комментарий обязательным. Больше ничего не меняй. Сначала покажи план.

## Что ты знаешь (говори только по вопросу)

- Workflow неактивный, ни к какому проекту не привязан; публикаций нет.
- Экраны «LOCAL-005-auto-screen1-{{RUN}}» и «LOCAL-005-auto-screen2-{{RUN}}» существуют; Comment в них не нужен.
- Порядок просьб: (1) на «Pause» назначить экран screen1 и сделать комментарий обязательным — одним планом, одним подтверждением; (2) после применения заменить на «Pause» экран на screen2.
- Другие переходы, экраны, правила и проекты менять нельзя.

## Как себя вести

- Подтверждай каждый показанный подходящий план ровно репликой «Да, применяй». Не подтверждай то, чего не видел.
- Если ассистент предлагает разбить первую просьбу на два отдельных плана — скажи, что нужен один план на обе правки.
- После применения (1) попроси: «Теперь замени на «Pause» экран на «LOCAL-005-auto-screen2-{{RUN}}».»
- Лишнее (публикация, проект, другой экран) отклоняй.

## Когда заканчивать

- DONE — после применения (2) и честного сообщения об итоге.
- GIVE_UP — три безрезультатных круга подряд.
