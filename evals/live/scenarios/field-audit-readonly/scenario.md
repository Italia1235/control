# Аудит поля с повторяющимся названием, только чтение (случайные названия)

Названия проекта и поля и ключ проекта runner подставляет случайно при каждом запуске (см. README, раздел «Случайные названия»). Перед диалогом `setup.mjs` создаёт проект {{KEY:proj}}, выпадающий список «{{NAME:field}}» (значения High, Medium, Low) с контекстом только в {{KEY:proj}} на всех экранах проекта, и второе, текстовое поле с тем же названием в глобальном контексте, ни на каких экранах. Проверяем чтение без записей:

- на неоднозначное название поля ассистент показывает всех кандидатов с типом и id и спрашивает, какое поле нужно, а не выбирает сам;
- контексты поля (проекты × типы задач) показаны по фактическим данным; «неизвестно» не выдаётся за «нет»;
- экраны проекта и вкладки экрана создания прочитаны по-настоящему;
- ни одного плана изменений, ни одного применения.

## Кто ты

Администратор Jira, не разработчик. Названий внутренних инструментов и API не знаешь и не подсказываешь ассистенту, что вызывать.

## Первая реплика

Ничего не меняй, только посмотри. Где действует поле «{{NAME:field}}» — в каких проектах и для каких типов задач? На каких экранах проекта {{KEY:proj}} оно стоит? И покажи, что вообще лежит на экране создания задач {{KEY:proj}}, по вкладкам.

## Что ты знаешь (говори только когда ассистент спросит)

- Тебе нужно поле «{{NAME:field}}», которое выпадающий список. Если ассистент покажет несколько полей с таким названием, выбери список.
- Проект — {{KEY:proj}} («{{NAME:project}}»).
- Экран создания — тот, что {{KEY:proj}} использует для создания задач.
- Менять ничего не нужно: ни поля, ни экраны, ни контексты.

## Как себя вести

- Если ассистент выбрал одно из полей сам, не спросив, — спроси, сколько полей с таким названием в Jira.
- Если ассистент предлагает что-то изменить (убрать дубликат, переименовать, поменять контекст, добавить или убрать поле с экрана) — откажись: сейчас только чтение.
- Если ассистент говорит, что какую-то часть прочитать нельзя, прими это, но попроси сказать прямо, что именно осталось непроверенным.
- Если ассистент спрашивает то, чего нет в разделе выше, ответь, что решать ему не надо, и попроси показать то, что он может прочитать.

## Когда заканчивать

- DONE — ассистент показал проекты и типы задач, где действует поле-список, экраны {{KEY:proj}} с этим полем и содержимое экрана создания по вкладкам (или честно объяснил, чего прочитать не удалось).
- GIVE_UP — ассистент ходит по кругу, трижды подряд не может ответить или пытается что-то изменить после отказа.
