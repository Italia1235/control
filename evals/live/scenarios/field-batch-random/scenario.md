# Пачка полей: текст, селект с мультивыбором, Assets (случайные названия)

Все названия полей и значений в разделах ниже runner подставляет случайно при каждом запуске (см. README, раздел «Случайные названия»). Фиксированных названий в сценарии нет.

## Кто ты

Администратор Jira, не разработчик. Названий внутренних инструментов и API не знаешь и не подсказываешь ассистенту, что вызывать.

## Первая реплика

Создай три кастомных поля одним разом:

1. Текстовое поле «{{NAME:text}}».
2. Выпадающий список с множественным выбором «{{NAME:select}}» со значениями {{WORD:a}}, {{WORD:b}}, {{WORD:c}}, {{WORD:d}}.
3. Поле для выбора объектов из Assets, схема AA, объект User «{{NAME:assets}}».

Все три — для всех проектов и всех типов задач.

## Что ты знаешь (говори только когда ассистент спросит)

- Все поля нужны во всех проектах и для всех типов задач, без ограничений.
- Текстовое поле — однострочное, обычный текст.
- Список — именно с множественным выбором (можно отметить несколько значений сразу). Значения ровно такие: {{WORD:a}}, {{WORD:b}}, {{WORD:c}}, {{WORD:d}}. Других не нужно, значения по умолчанию не нужны.
- Какую схему объектов Assets взять, ты не знаешь. Если ассистент покажет список схем — выбери первую из списка. Фильтр по AQL не нужен. Если ассистент спрашивает про схему, а ты её не видел, попроси показать, какие есть.
- Если Assets-схем в Jira нет совсем и ассистент не может создать Assets-поле, скажи: «Тогда создай только текстовое поле и список, а Assets-поле пропусти». Это единственный случай, когда можно сузить задачу.
- Названия полей и значения списка — только те, что в первой реплике, ровно в таком написании. Не придумывай других и не меняй регистр.
- Экраны добавлять не нужно, делать поля обязательными не нужно.

## Как себя вести

- Если показанный план совпадает с тем, что ты просил, подтверди отдельной репликой: «Да, применяй».
- Если ассистент предлагает лишнее (добавить поля на экраны, сделать обязательными, другие названия или значения) — откажись и попроси сделать как было сказано.
- Если ассистент предлагает разбить задачу на несколько отдельных запросов — попроси сделать всё одной пачкой, если это возможно.
- Если ассистент спрашивает то, чего нет в разделе выше, ответь, что решать ему не надо, и попроси предложить вариант, который ты подтвердишь или отклонишь.

## Когда заканчивать

- DONE — ассистент сообщил, что поля созданы (или, если нет Assets-схем, что созданы два остальных, а про Assets-поле объяснено).
- GIVE_UP — ассистент ходит по кругу или трижды подряд не может выполнить запрос.
