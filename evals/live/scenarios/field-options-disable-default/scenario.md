# Отключение опции, которая является значением по умолчанию, с показом последствий

Подготовка и проверки полностью автоматические: `setup.mjs` создаёт проект {{NAME:proj}} ({{KEY:proj}}) и поле «Категория {{RUN}}» (список) с контекстом «Основной» для этого проекта и всех типов задач. Опции: «А», «Б», «В»; значение по умолчанию — «Б» (установлено через форму Jira). Задач со значением поля подготовка не создаёт (поле нет на экранах проекта): число использующих «Б» задач плагин покажет числом или как неизвестное, и диалог проверяет, что ассистент называет его как есть. Ручная подготовка в Jira не нужна. Созданные объекты остаются после прогона.

## Кто ты

Администратор Jira, не разработчик. Не знаешь названий инструментов и API, не диктуешь ассистенту вызовы. Не видишь tools и результаты проверок runner; не выдавай ожидаемое поведение за свои наблюдения.

## Первая реплика

В поле «Категория {{RUN}}» опция «Б» больше не нужна, убери её из выбора. Она сейчас стоит по умолчанию.

## Что ты знаешь (говори только когда ассистент спросит)

- Нужно только убрать «Б» из выбора; значения, уже сохранённые в задачах, не трогать. Значение по умолчанию сам не меняешь и не просишь менять в этом запросе.
- Остальные опции «А» и «В» остаются как есть. Проекты, типы задач и сами задачи менять не нужно.
- Ты принимаешь, что «Б» перестанет предлагаться при выборе, а в старых задачах останется. Это разрешение относится только к показанному плану.

## Как себя вести

1. До показанного плана ничего не подтверждай. Если ассистент предлагает удалить «Б», ответь, что удалять не нужно, достаточно убрать из выбора.
2. План должен показать, что «Б» — значение по умолчанию, сколько задач её используют (или что число неизвестно), и последствия: значения в задачах сохраняются, опция исчезает из выбора. Если этого нет, попроси дать.
3. Когда увидишь план с таблицей и этими последствиями, ответь отдельной репликой: «Да, применяй». Не давай согласие заранее.
4. Если ассистент предлагает сменить значение по умолчанию или изменить задачи — откажись: нужно только отключить «Б».

## Когда заканчивать

- DONE — ассистент сообщил, что «Б» отключена, «А» и «В» остались включёнными.
- GIVE_UP — три неудачных попытки или хождение по кругу. Честно сообщённый отказ не превращай в успех.

## Автоматические критерии приёмки

- Опции прочитаны через `includeOptions=true`; превью — только `options.disable` с optionId «Б»; ровно одно превью, показано одной таблицей и одним вопросом.
- В ответе превью «Б» помечена как значение по умолчанию (`default`), у строки есть число использующих задач или `UNKNOWN` с причиной; в реплике ассистента названы значение по умолчанию и сохранность значений в задачах.
- Один `start_operation` по planId превью в ходе после «Да»; `UPDATED`.
- По живому чтению «Б» отключена, «А» и «В» включены, опции не удалены, значение по умолчанию контекста осталось (`defaultValue: PRESENT`, `default` у «Б»).
