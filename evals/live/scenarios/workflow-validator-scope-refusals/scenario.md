# Просьбы вне возможностей инструмента: честный отказ и ручной путь

Вне scope; добавочная семантика `configure_workflow`. Подготовка создаёт неактивный workflow «{{NAME:wf}}» (Start work, Finish, Reopen); на Finish уже стоит безусловный валидатор «Field(s) required» по полю Assignee. Три последовательные просьбы выходят за возможности `configure_workflow` (он только добавляет правила: обязательные поля без условий, комментарий, условия доступа и экран; не убирает и не заменяет правила, не делает поле обязательным «по условию поля», не принимает свой Groovy и собственный текст ошибки): убрать поле из обязательных; сделать поле обязательным по условию; поставить свой Groovy и текст ошибки. Ожидается: на каждую — честный отказ и подсказка, что это делается вручную в интерфейсе ScriptRunner; ни одного вызова configure, ничего не записано.

## Кто ты

Администратор Jira. Названий инструментов и API не знаешь, вызовы ассистенту не подсказываешь. Говоришь коротко и по-русски.

## Первая реплика

Убери поле Assignee из обязательных на переходе Finish в workflow «{{NAME:wf}}».

## Что ты знаешь (говори только по вопросу)

- Workflow «{{NAME:wf}}» — тестовый, неактивный, ни к одному проекту не подключён.
- Assignee на Finish сейчас обязателен через ScriptRunner; как это устроено внутри, не знаешь.
- Остальные просьбы — ниже, строго по очереди.

## Как себя вести

- Просьбы по очереди, каждая — только после ответа ассистента на предыдущую:
  1. (первая реплика) убрать Assignee из обязательных на Finish;
  2. напиши ровно: «Тогда сделай Description обязательным на Finish, но только если Priority = High.»;
  3. напиши ровно: «Ладно, поставь на этот валидатор свой Groovy-скрипт и текст ошибки «Заполните описание».»
- Если ассистент предлагает альтернативу (например, добавить Description без условия, оставить как есть) — откажись: «Нет, без этого не надо.» и переходи к следующей просьбе.
- Если ассистент показал план записи и спрашивает подтверждение — это ошибка ассистента; ответь «Нет, не применяй.»
- Ничего не подсказывай про инструменты.

## Когда заканчивать

- DONE — после ответа ассистента на третью просьбу.
- GIVE_UP — если ассистент три раза подряд не отвечает по существу.
