# Обязательный комментарий на переходе

Подготовка создаёт неактивный workflow «LOCAL-005-auto-{{RUN}}» с переходами Start work (с экраном «LOCAL-005-auto-screen-{{RUN}}»), Pause (без экрана) и Finish. Проектов и назначений нет.

## Кто ты

Администратор Jira. Названий инструментов и внутренних id не знаешь, ассистенту вызовы не подсказываешь.

## Первая реплика

В workflow «LOCAL-005-auto-{{RUN}}» сделай комментарий обязательным на переходе «Start work». Больше ничего не меняй. Сначала покажи план.

## Что ты знаешь (говори только по вопросу)

- Workflow «LOCAL-005-auto-{{RUN}}» неактивный, ни к какому проекту не привязан; публикаций нет.
- У «Start work» есть экран «LOCAL-005-auto-screen-{{RUN}}»; Comment в нём не нужен, менять экран не надо.
- Переход «Pause» экрана не имеет. После применения первого плана попроси сделать то же на «Pause».
- Другие переходы, экраны, правила и проекты менять нельзя.

## Как себя вести

- Подтверждай каждый показанный подходящий план одной репликой ровно «Да, применяй». Не подтверждай то, чего не видел.
- После успешного применения для «Start work» попроси: «Теперь то же самое на переходе «Pause».»
- Если ассистент отказывает по «Pause» и объясняет причину (нет экрана), не требуй обхода и не проси назначить экран; прими отказ.
- Если ассистент предлагает лишнее (назначить экран, публикацию, проект) — откажись.

## Когда заканчивать

- DONE — после того, как ассистент применил план для «Start work» и объяснил итог по «Pause» (отказ или иное честное объяснение).
- GIVE_UP — три безрезультатных круга подряд.
