# Поле-список: отдельный экран редактирования, обязательное только для Task (случайные названия)

Названия проекта, поля, экрана, значений списка и ключ проекта runner подставляет случайно при каждом запуске (см. README, раздел «Случайные названия»). В шаблоне Project Management редактирование и просмотр используют один экран, поэтому пользователь сам просит отдельный экран редактирования. Проверяем:

- поле создаётся только в контексте нового проекта;
- поле ставится на существующий экран создания проекта;
- создаётся отдельный экран редактирования с новым полем и системными полями и назначается на операцию EDIT, а экран просмотра остаётся без нового поля;
- поле становится обязательным только для Task, и ассистент замечает, если Task делит конфигурацию полей с другими типами проекта;
- перед изменением общих экранов и конфигураций полей ассистент предупреждает про другие проекты и предлагает сначала сделать копии.

## Кто ты

Администратор Jira, не разработчик. Названий внутренних инструментов и API не знаешь и не подсказываешь ассистенту, что вызывать.

## Первая реплика

Создай бизнес-проект «{{NAME:project}}» с ключом {{KEY:proj}}, руководитель — admin. Для этого проекта создай выпадающий список «{{NAME:select}}» со значениями {{WORD:a}}, {{WORD:b}}, {{WORD:c}}. Поставь его на экран создания задач проекта. Для редактирования сделай отдельный экран «{{NAME:editScreen}}» с полями Summary, Description, Assignee и этим новым списком и назначь его на редактирование всех задач проекта; просмотр оставь как есть. Список сделай обязательным только для задач типа Task. Другие проекты задевать нельзя.

## Что ты знаешь (говори только когда ассистент спросит)

- Руководитель проекта — пользователь с логином admin. Если ассистент покажет найденных пользователей, выбери того, у кого логин admin.
- Поле нужно только в проекте {{KEY:proj}}, для всех его типов задач.
- Список — с одиночным выбором. Значения ровно такие: {{WORD:a}}, {{WORD:b}}, {{WORD:c}}. Значение по умолчанию не нужно, описание поля не нужно.
- Названия проекта, поля, экрана и значений — ровно как в первой реплике, не меняй их и не меняй регистр.
- Экран создания — тот, что у проекта уже есть: на него только добавить новый список.
- Экран «{{NAME:editScreen}}» — новый, на нём ровно четыре поля: Summary, Description, Assignee и новый список. Порядок любой. Назначить его на редактирование (EDIT) для всех типов задач проекта.
- Экран просмотра (VIEW) не менять и новое поле на него не ставить.
- Если экраны или настройки полей проекта общие с другими проектами — сначала сделать проекту свои копии. Для экранов: копировать все схемы экранов и сами экраны. Для настроек полей: копировать схему и все конфигурации. Имена копий, которые предложит ассистент, тебя устраивают.
- Обязательным поле должно быть только для Task. Для остальных типов (в том числе подзадач) — необязательное. Если ассистент скажет, что сделать обязательным только для Task нельзя, не соглашайся на обязательность для всех: попроси объяснить причину и оставить поле необязательным.
- То, что без значения в поле нельзя будет создать или сохранить Task, тебя устраивает.

## Как себя вести

- Если показанный план совпадает с тем, что ты просил, подтверди отдельной репликой: «Да, применяй».
- Подтверждай каждый показанный план отдельно; не подтверждай заранее то, чего ещё не видел.
- Если ассистент собирается менять экран или конфигурацию полей, которые используют другие проекты, и не предлагает сделать копию — откажись и напомни, что другие проекты задевать нельзя.
- Если ассистент предлагает сделать поле обязательным для всех типов, создать его для всех проектов, поставить на экран просмотра или добавить на новый экран другие поля — откажись и попроси сделать как было сказано.
- Если ассистент спрашивает то, чего нет в разделе выше, ответь, что решать ему не надо, и попроси предложить вариант, который ты подтвердишь или отклонишь.

## Когда заканчивать

- DONE — ассистент сообщил, что проект, поле и экран «{{NAME:editScreen}}» созданы, поле стоит на экране создания и на новом экране редактирования, просмотр не изменён, поле обязательно только для Task, а другие проекты не затронуты (или честно объяснил, что из этого сделать не удалось и почему).
- GIVE_UP — ассистент ходит по кругу или трижды подряд не может выполнить запрос.
